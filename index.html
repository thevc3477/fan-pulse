TRANSPARENT METHODOLOGY

How Every Number Is Computed

Data Sources & Scoring Pipeline

  • Kalshi Market Odds: Fetched directly from Kalshi's public v2 API (/trade-api/v2/events/{ticker}?with_nested_markets=true). Mid-price is computed from live yes_bid_dollars and yes_ask_dollars and normalized head-to-head across the two compared contenders so percentages sum to 100% (raw multi-outcome contract prices in cents are shown alongside).
  • 7-Day X Buzz Share: Exact 7-day English non-retweet post counts per side via X's recent count endpoint (-is:retweet lang:en).
  • Sampled Post Sentiment: Non-spam, non-ticket posts sampled per event are scored deterministically by a transparent rule-based lexicon in Python, excluding @KalshiSports market-news tweets and deduplicated to max 1 directional vote per unique X handle so reply-bots cannot skew the sample.
Crowd % = 0.50 * (7d Buzz Share %) + 0.50 * (Deduplicated Sample Sentiment %)
Divergence (pp) = Crowd % (Side A) - Kalshi H2H % (Side A)

Honest Caveats & Refresh Cadence

  • Snapshot vs. Live Odds: Kalshi odds can be refreshed anytime via scripts/refresh_kalshi.py (and scheduled via GitHub Actions). X post counts and sentiment remain pinned to the timestamped Nov 24, 2026 4:57 PM CT snapshot so X API limits are respected and every cited post stays verifiable.
  • Known Limitations: Keyword/lexicon scoring on public English X posts captures directional buzz and narrative lean rather than full human sarcasm or private group chats; neutral/two-sided commentary is excluded from the directional denominator and reported transparently in n.
  • Contract Volume Note: Kalshi contract volumes reflect $1 notional payout contracts traded across the market.
